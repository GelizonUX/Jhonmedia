# Thumbnails

Drop one vertical frame per ad in this folder.

- Size: 9:16. 1080x1920 is ideal, 720x1280 is fine.
- Format: JPG, under 250KB.
- Names: `01.jpg`, `02.jpg` ... `09.jpg`, matching the `thumbnail` paths in `assets/js/work.js`.

No image yet? Leave the path in `work.js`. The site shows a gray numbered placeholder until the file exists.
Adding a 10th ad? Save `10.jpg` here and add a block in `work.js` with `thumbnail: "assets/thumbs/10.jpg"`.
